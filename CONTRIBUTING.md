# Contributing to genesis-ouroboros

Thanks for your interest! This project follows its own constitution — the nine principles and operating rules in `genesis-ouroboros/SKILL.md`.

## Quick Start

1. Fork & clone
2. Make changes
3. Submit PR

## Commit Message Convention

```
feat: <what you added>
fix: <what you fixed>
docs: <what you documented>
```

## SKILL.md Changes

SKILL.md is the constitution. Changes to it require:
1. Explain the rationale in your PR
2. Update CHANGELOG.md

## Reporting Issues

- Bugs: include steps to reproduce + expected vs actual
- Design suggestions: explain which principle and why
- Security issues: see SECURITY.md or DM the maintainer
